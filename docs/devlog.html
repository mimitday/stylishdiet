カメラフィルター修正 + 中央タップUX
実装
フィルター (B&W / Sepia / Fade / Hi-Con) が iOS Safari で一切効かなかった問題を修正。 ctx.filter（Safari 16以下で未サポート）を廃止し、getImageData → camFilterPixels() → putImageData に置き換え。 全フィルターをピクセル操作で実装（grayscale / sepia matrix / saturate / contrast / brightness を手書き計算）。
中央プレビューエリア (cam-preview-area) をタップで写真選択できるように変更。 プレースホルダー・写真表示中どちらをタップしても input[type=file] が開く。 cursor: pointer を追加。
却下・断念
ctx.filter の CSS フィルター文字列方式はそのまま残す案 → iOS 対応が保証できないため廃止。 PixiJS 等の外部ライブラリ導入案 → 最小構成ルールにより却下。
話した内容
運動できていない原因を深掘り → 種目名を見ても動きがピンとこないものが多い。 求めるレベル感：「スクワット」「プリエスクワット」くらいに "なんとなく動きが想像できる" ならOK。
desc フィールド（日本語説明）はデータとして既に全種目に存在している。 UIに表示していないのが問題 → 表示改善＋ピクトグラムで解決できる見込み。
